## 2. 読み方

A の図の凡例（印の形）:

| 印 | 意味 |
|---|---|
| 箱の中に上下の矢印と人 | エレベーター |
| 黒く塗った三角 | 入口（自動扉） |
| 半分だけ黒い三角 | 入口（開き戸などあり）。車椅子での利用は勧めない |
| 白抜きの三角 | 入口（階段などあり）。車椅子では使えない |
| 車椅子の人と男女の人 / 男の人 / 女の人 | 多機能トイレ / 男性用トイレの中の多機能トイレ / 女性用トイレの中の多機能トイレ |
| 人の絵に十字 | オストメイト対応の多機能トイレ |
| 青い点線の矢印（頭が 1 つ） | スロープ |
| 青い点線の矢印（頭が 3 つ重なる） | 急な坂道 |

- 三角の向きは建物に入る向きを表すだけで、種類は塗り方で決まる。印ごとに切り出して拡大し、塗り方を 1 つずつ目で確かめた。
- 図に方位記号と縮尺は無い。位置は「図の上・下・左・右」で書いた。JSON の `px` は図の画像の左上を原点にした印の中心のおおよその位置で、シーンの座標には直していない。
- JSON の判定の決め方:
  - `elevator`: 図の建物の中にエレベーターの印があれば `yes`。印が無い建物は「無い」とは書かれていないので `unknown` にし、note に「印なし」と書いた。
  - `accessibleEntrance`: 外からの入口に自動扉の印が 1 つ以上あれば `yes`。外からの入口がすべて「開き戸など（勧めない）」か「階段など（使えない）」なら `no`。入口の印が無ければ `unknown`。外の入口が無く連絡通路の入口だけが自動扉の建物（第4学舎4号館）は `yes`・confidence `medium`。
  - `accessibleRestroom`: 多機能トイレの印と説明があれば `yes`、無ければ `unknown`。
- トイレの設備（オストメイト対応・固定式と可動式の手すり・回転スペース・背もたれ・介助用ベッド・点字ガイド）は資料の ○ × △ をそのまま JSON に入れた。△ の意味は資料に説明が無い。

- 関大前通り（PDF p.5〜7）: 関大前駅の北口（東側）から線路沿いに進み、踏切の手前で右（地図では東）へ曲がって、関大前通りを正門まで上る。坂は約6〜9°、正門の近くは約10〜11°でタイル張り（雨の日は滑りやすい）。4 ルートで段差が最も少ないが、手すりと点字ブロックはほぼ無く、車・自転車が通り、授業の前後は混む。
- 西門（PDF p.8〜11）: 北口を出て左に曲がるとすぐ西門で、そこから階段を上る。通路を抜けた先でエスカレーターと階段に分かれ、どちらも第3学舎3号館に着く。地図では、最初の階段（黄の枠）の先で階段（黄）とエスカレーター（青）が並んで第3学舎の図の左下の角まで延びる。3号館の入口前から、左へ坂を下ると第1学舎方面、右へ進み大学会館の手前で左に曲がって坂を下ると第2・第4学舎方面。手すりは多いが、手すりのある所に雨よけの屋根は無い。点字ブロックは西門から階段・エスカレーターの手前まで。エスカレーターは授業日（土曜を含む）の 8:00〜11:00 が全機上り、11:00〜18:30 が通常運転（2019〜2021 年の資料）。
- 南門（PDF p.12〜17）: 関大前駅の南口（両方のホームにエレベーター）の前の南門から入る。門の右手のスロープ（傾き 1°未満、両側に手すり、幅は人がすれ違えるかどうか）で階段を上らずにエスカレーターに乗れるが、エスカレーターが止まっている時はスロープも閉まる。最初の段は階段とエスカレーター（雨よけの屋根つき）に分かれ、上で合流して次の分岐まで平ら。そこから Ⓐ階段（約65m、狭い、踏面の奥行きが約30〜80cmで不揃い、手すりあり、かなり急）、Ⓑ坂道（最大約8°、カーブしながら約75m、途中から片側に手すり、車椅子は介助者が必須）、Ⓒエスカレーター（資料の推奨、屋根つき）、Ⓓ関大一中・一高へ下る坂、に分かれる。Ⓐ〜Ⓒは 100周年記念会館前の広場で合流し、その先はほぼ平ら。手すりは踊り場で途切れ、点字ブロックはほぼ無い。
- 千里山（PDF p.18〜22）: 千里山駅の西口から住宅地を通って北門へ。駅から 2 つ目の信号（交差点a）で右折するまでは点字ブロックがあり、道幅 2m 以上で平ら（車椅子などは信号を渡ってから右折するよう勧めている）。交差点b まではゆるい上り坂、その先は歩道を進み 2 つ目の角を右折して交差点c（横断歩道なし）。北門の手前は急な坂で歩道が無く、門の入口は幅約1m。門を抜けると第1学舎5号館の裏に出る。

## 7. 造形に使える副産物（資料 B の写真から読んだこと。2019 年の調査時点）
