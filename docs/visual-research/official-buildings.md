## 読んだ資料

- KAN-CAN! 学舎・教室（千里山キャンパス）の建物別・階別の部屋一覧と、イラストマップ（全体と第1〜第4学舎・誠之館・新関西大学会館）。階数は「部屋の表示がある最上階」で、屋上階や塔屋は含まない可能性がある
- 年史編纂室 CAMPUS GUIDE MAP の学舎別エリア紹介（第1〜第4学舎）、村野建築を巡るコース（5ページ）、コラム（村野藤吾）、歴史的景観
- 公式サイトの PDF 版キャンパスマップは見つけられなかった（探した範囲の URL は 404）。マップは上のイラストマップを画像で見て位置を読んだ
- イラストは斜め見下ろしで縮尺が正確でなく、方位記号も無い。画面の上がおおよそ東、左がおおよそ北と読んで輪郭と対応させた。位置による対応は confidence を low〜medium にしてある
- OSM の名前・building:levels は Overpass で 2026-11-19 時点を取得（出典 OpenStreetMap contributors、ODbL）。start_date・architect のタグは対象の建物すべてで空
