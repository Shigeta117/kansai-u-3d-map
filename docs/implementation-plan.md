# 実装計画（implementation plan）

v0.2（2026-11-19）の監査を受けた直しの計画。段ごとにブランチと PR を分け、終わったら状態を更新する。

最終更新: 2026-11-20

## 方針

- 安全に関わる表示（段差フリー・車いす対応）を最優先にする。出典の無い値は「未確認」にする
- 建物の外観は、出典のある特徴だけで作る。写真に無い要素は作らない
- スマホで快適に動くこと（地図式の操作、必要なときだけ描画）

## 造形の物差し

1. 写真に無い要素がゼロ（最優先）
2. ラベルなしのスクショで、キャンパスを知る人が棟名を当てられる
3. 目印 3 点が正しい面にある
4. 高さと幅の比が写真と ±2 割以内

## 保留

- フロアマップ: 大学との調整待ち（公開されない可能性がある）
