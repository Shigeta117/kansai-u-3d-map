## 2. 座標系とジオラマ投影設計

- **投影原点（千里山キャンパス）**: `34.7745°N, 135.5105°E`
- **右手系 Y-up ローカル座標（単位: m）**:
  - `+X` = 東方向（`Δlon × 111320 × cos(originLat)`）
  - `-Z` = 北方向、`+Z` = 南方向（`-Δlat × 110940`）
  - `+Y` = 標高方向（地形メッシュ・ルート表示は垂直強調率 `1.35` を適用）
- **ジオラマ範囲**: `x ∈ [-540, 580]`（東西 `1,120m`）、`z ∈ [-480, 580]`（南北 `1,060m`）
- **実測チェックポイント標高（GSI DEM5A）**:
  - 阪急 関大前駅: `25.64m`
  - 関西大学 正門: `37.08m`
  - 悠久の庭: `41.34m`
  - 第1学舎1号館（高台）: `53.24m`

## 3. オープンソースにおけるライセンス分離方針

1. **MIT License（コード・独自造形）**:
   - `src/` 以下のアプリケーション・3Dエンジン・探索ロジックおよび `scripts/` 以下の変換・書き出しツールは MIT License とします。
2. **生データキャッシュの分離（`.cache/`）**:
   - `scripts/fetch-open-data.mjs` が取得する生の OSM JSON や DEM PNG タイルは `.cache/raw/` に保存され、`.gitignore` により Git リポジトリへ直接同梱しません。
3. **成果物データ・クレジット継承（`public/data/`, `exports/`）**:
   - 変換後の Web 用軽量データおよび `.glb`/`.obj` 出力は ODbL の **Produced Work** および国土地理院利用規約に基づき生成されます。再配布時は `THIRD_PARTY_NOTICES.md` およびアプリ内の出典表示を維持してください。
